#Demo app(Login, Signup, Logout, Splash)

This Android application demonstrates a simple and clean user authentication flow with **Splash Screen**, **Login**, **Signup**, and **Logout** functionality. It is ideal for beginners who want to understand how user sessions and screen transitions work in Android.

---

## 🚀 Features

- ✅ **Splash Screen** – Introduces the app with a short delay.
- ✅ **User Signup** – Register new users with input validation.
- ✅ **User Login** – Authenticate existing users securely.
- ✅ **Logout Functionality** – Ends user session and redirects to login screen.
- ✅ Clean UI with navigation between all screens.

---

## 🛠️ Tech Stack

- **Android Studio**
- **Java / Kotlin**
- **XML for Layout**
- **SQLite** or **SharedPreferences** (for session management) 

---

## 📲 Screens

- `SplashActivity`
- `SignupActivity`
- `LoginActivity`
- `HomeActivity` (after login)
- Logout handled within `HomeActivity` or via button
